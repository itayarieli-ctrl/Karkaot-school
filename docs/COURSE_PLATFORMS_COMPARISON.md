# השוואת פלטפורמות קורסים — קרקע 101

## עקרון מנחה

אתם **לא צריכים לבנות פלטפורמת קורס**. צריך לבחור SaaS שמטפל ב:
- אחסון וידאו ושליחתו לסטרים
- אזור משתמש מאובטח (login, gating, גישה לפי קורס)
- גביית תשלום + חידוש מנוי
- שליחת תזכורות וקבלות אוטומטית
- ניטור התקדמות (איזה שיעור הסטודנט סיים)

הקריטריונים העיקריים שלכם, לפי סדר עדיפויות:

1. **תמיכה ב-RTL ועברית** — לא רק תרגום ממשק, אלא RTL אמיתי בנגן הוידאו ובכל זרימת המשתמש
2. **חשבונית מס ישראלית אוטומטית** — חיבור ל-EZcount / Green Invoice / iCount
3. **סליקה בישראל** — תמיכה ב-Cardcom / Yaad-pay / Tranzilla, או PayPal ככיסוי משלים
4. **עומק תכונות** — קוויזים, פורום, לייב, certificates (לפי שלב)
5. **עלות חודשית**
6. **קלות שימוש לאדם לא טכני**

## האפשרויות

### 1. Doko (doko.co.il) — פלטפורמה ישראלית

**יתרונות**:
- ישראלית במקור — תמיכה מלאה ב-RTL ועברית, ממשק עברי
- חשבוניות מס מובנות
- סליקה ישראלית מובנית
- תמיכה מקומית בעברית
- מתאים גם למורים בודדים וגם לבתי ספר

**חסרונות**:
- פחות עמוקה מ-Teachable/Kajabi בכלים שיווקיים (אוטומציות, A/B testing)
- מותג פחות מוכר → אם תרצו להציג "כמו Coursera" זה לא בדיוק הויב

**מחיר**: בערך 99-299 ש"ח/חודש לפי תוכנית. צריך לוודא בשיחה.

**מתאים לכם אם**: רוצים את הפתרון הכי "תוצרת ישראל" — בלי לפצח חיבור EZcount/Cardcom בעצמכם.

---

### 2. Teachable (teachable.com)

**יתרונות**:
- הסטנדרט העולמי לקורסים — אמין ובוגר
- תמיכת RTL סבירה (לא מושלמת, צריך לבדוק עם דף תצוגה)
- ממשק נקי לתלמיד, אזור משתמש מקצועי
- אינטגרציה ל-Zapier/Make (חיבור לכל דבר)
- אפשרות לחבר Green Invoice/EZcount דרך Make
- תוכניות בחינם להתנסות (עם עמלה 10%)

**חסרונות**:
- עברית/RTL לא נטיב — דורש התאמות CSS קלות
- סליקה מובנית של Teachable עובדת רק עם USD (לא ש"ח) → צריך לחבר ב-Stripe/PayPal
- אם רוצים לגבות בש"ח דרך Cardcom → מורכב יותר
- מחיר באנגלית בלבד; חשבונית מס דרך Make/Zapier → EZcount

**מחיר**: $39-$199 בחודש (תלוי בתוכנית). תוכנית Basic מספיקה להתחלה ($39 ≈ 140 ש"ח).

**מתאים לכם אם**: אתם רוצים פלטפורמה בוגרת ופופולרית, מוכנים לחבר חשבוניות דרך Make, ובסדר עם סליקה בש"ח דרך שירות חיצוני.

---

### 3. Thinkific (thinkific.com)

**יתרונות**:
- דומה ל-Teachable, מעט יותר נדיב בתוכנית החינמית
- אינטגרציות דומות
- ביצועים טובים

**חסרונות**:
- אותם חסרונות כמו Teachable עבור השוק הישראלי
- מותג פחות מוכר

**מחיר**: $0 (חינם עם מגבלות) — $99/חודש.

**מתאים לכם אם**: רוצים להתחיל בחינם לבדוק את המים. ניתן להעביר ל-Teachable/Kajabi אחר כך.

---

### 4. Kajabi (kajabi.com)

**יתרונות**:
- "סוכנות בקופסה" — קורסים, אימייל מרקטינג, דפי נחיתה, אזור חברים, כל הקאמפיין בכלי אחד
- חזק במיוחד ל"פלטפורמת מומחה" כמו שאתם בונים
- ביצועים מצוינים

**חסרונות**:
- יקר משמעותית ($149-$399/חודש)
- עברית/RTL — דורש חיוב התאמות
- Overkill אם אתם מתחילים בקטן

**מחיר**: $149-$399/חודש.

**מתאים לכם אם**: אתם בטוחים בפלטפורמה לטווח ארוך, ויש 100+ סטודנטים בחודש שמצדיקים את העלות.

---

### 5. WordPress + LearnDash או TutorLMS (לא מומלץ עבורכם)

**יתרונות**:
- נשאר בתוך WordPress שכבר יש לכם
- שליטה מלאה
- עלות חד פעמית (~$199/שנה)

**חסרונות הקריטיים לכם**:
- **מצריך תחזוקה טכנית** — תוסף LMS = שכבה מורכבת על WordPress, נשבר באופן קבוע בעדכונים
- אבטחה: WordPress הוא יעד מועדף להאקרים, ובמיוחד אתר עם תשלומים
- חיבור לסליקה: דורש תוסף WooCommerce + WooCommerce Subscriptions + תוסף Cardcom = 3 שכבות שצריך לתחזק
- ביצועים: דפי וידאו עם LMS על Elementor הם איטיים

**המלצה**: **אל תלכו לכיוון הזה ללא איש טכני קבוע.** עלות אמיתית מצטברת לכם ל-1,500-3,000 ש"ח/חודש בתחזוקה. לא חוסך.

## המלצה

לאור: לא טכניים, ללא איש טכני, רוצים להתחיל מהר, חוקי ישראל (חשבונית מס) —

**בחירה ראשונה: Doko** (אם אכן תומך בכל מה שצריך — צריך לבדוק בשיחה).

**בחירה שנייה: Teachable + Make.com + EZcount**.

ההבדל הוא: Doko = פתרון אחד שאני מקווה שיעבוד. Teachable = הרכבת 3 שירותים שאני יודע שיעבדו אבל דורשים הקמה ראשונית.

ל-MVP — לכו עם Doko. אם תיתקלו בקיר (תכונה חסרה, ביצועים, מחיר), הגירה ל-Teachable דחיפה תוך שבוע.

## מה לבדוק לפני שמחליטים סופית

1. **Doko**: לתאם דמו עם רכזת המכירות. לשאול קונקרטית:
   - תמיכה ב-RTL מלא בנגן הוידאו ובכל הדפים?
   - חשבונית מס אוטומטית לכל רכישה?
   - אפשרות לסליקה חד-פעמית וחיוב חודשי?
   - מה קורה בעת ביטול מנוי — אוטומטי או ידני?
2. **Teachable**: לפתוח חשבון חינמי, להעלות שיעור דמה בעברית, לבדוק איך RTL נראה.
3. **לבדוק רכוז הלקוחות**: Scalla CRM — האם יש להם native integration עם אחת מהפלטפורמות, או שצריך Make?

## תקציב משוער חודשי (MVP)

| רכיב | עלות |
|---|---|
| פלטפורמת קורס (Doko / Teachable) | 150-350 ש"ח |
| EZcount (אם לא מובנה) | 50-100 ש"ח |
| Make.com (תוכנית Core) | 40 ש"ח |
| אחסון וידאו (אם לא מובנה ב-SaaS) | 0-100 ש"ח |
| Vercel (לדף הנחיתה) | 0 |
| **סה"כ** | **240-590 ש"ח/חודש** |

ברגע שתעברו 50 רוכשים בחודש — הוצאה זניחה. אבל יש להבטיח שלא יישרפו 590 ש"ח/חודש לאורך 6 חודשים ללא הכנסה.

המלצה: לפתוח Doko רק כשיש לכם מועד פתיחה ולפחות 15 נרשמים ברשימת המתנה.
